# 信源雷达 XyRadar · 下载

定时巡检一批政府 / 使馆 / 媒体 / 协会的列表页，把新出的条目抓回来、按发布时间
倒排展示，并支持站内直接读全文。本地单机运行，`http://127.0.0.1:5057`，不留外网入口。

**这个仓库只放编译好的程序，不放源码。**

## 下载

到 [Releases](https://github.com/pjhuang99/xy-radar-releases/releases/latest) 里按自己的电脑选：

| 你的电脑 | 下哪个 |
| --- | --- |
| Mac（M1 / M2 / M3 / M4） | `信源雷达-mac-arm64-….zip` |
| Mac（Intel Core） | `信源雷达-mac-x86_64-….zip` |
| Windows | `信源雷达-win64-….zip` |

不确定 Mac 是哪种芯片：左上角  →「关于本机」→ 看「芯片」。
写着 `Apple M…` 就是 arm64，写着 `Intel Core` 就是 x86_64。

## 怎么用

解压之后照包里的 `首次打开说明.txt` 做。要点：

- **不用装 Python，不用装任何依赖**，双击就跑。
- 那个黑窗口 / 终端窗口就是服务本身，留着别关，关掉就等于停止采集。
- macOS 第一次打开要过一道「未签名程序」的门，说明里写了两步常规做法 ——
  不是让你关掉系统安全设置。
- 数据存在程序旁边的 `data/` 文件夹里（`radar.db` 就是全部数据），
  各人一份、互不影响；想备份或换机器，拷走这个文件夹就行。

## 几个已知情况

- 程序自带 80 多个信源，第一次打开新闻流是空的，点一下「修复源新闻采集」就有内容了。
- 港澳台那几个源在内地直连不通，默认是暂停的；有代理时到「来源管理」里恢复即可，
  恢复后下一轮会把最近的内容补进来。
- 有一个源需要额外的无头浏览器才能抓，安装包里默认暂停，用不着就一直停着。

有问题或想要的功能，直接在这个仓库开 [Issue](https://github.com/pjhuang99/xy-radar-releases/issues)。
